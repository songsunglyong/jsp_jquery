# Codex 작업 규칙

1. 작업을 시작하기 전에 이 문서와 [PROJECT.md](PROJECT.md), [TODO.md](TODO.md), [DECISIONS.md](DECISIONS.md)를 순서대로 읽는다.
2. 현재 파일과 Git 상태를 확인하고, 사용자의 기존 변경을 보존한다. 요청 범위 안에서 변경한다.
3. 실행 및 설치 명령은 프로젝트에서 확인한 뒤 [README.md](README.md)에 기록한다. 검증하지 못한 항목은 작업 결과에 밝힌다.
4. 작업을 마치면 [TODO.md](TODO.md)의 상태를 갱신하고, 완료한 변경과 확인 결과를 [CHANGELOG.md](CHANGELOG.md)에 기록한다.
5. 중요한 설계 결정을 내리면 [DECISIONS.md](DECISIONS.md)에 결정과 이유를 남긴다. 프로젝트 구조가 바뀌면 [PROJECT.md](PROJECT.md)도 갱신한다.
6. 비밀값과 로컬 전용 설정은 커밋하지 않는다. 원격 저장소의 공개 범위를 변경하기 전에 사용자 지시를 확인한다.

# 주요 결정

## 2026-11-10 — 프로젝트 문서는 `doc/`에서 관리

요청한 문서 6개를 한곳에 두고 서로 링크한다. Codex는 작업 전 개요와 지침을 읽고, 작업 후에는 할 일과 변경 이력을 갱신한다.

## 2026-11-10 — GitHub 저장소는 비공개로 운영

사용자 요청에 따라 새 저장소는 비공개로 생성한다. 저장소 이름은 작업 디렉터리와 같은 `jsp_jquery`를 사용한다.

## 2026-11-12 — 포트폴리오 공개

사용자 요청에 따라 GitHub 저장소를 공개로 전환한다. 이 결정은 초기 비공개 운영 결정을 대체한다. 이력서에서 소스와 실행 방법을 확인할 수 있도록 구현과 문서를 함께 게시한다.

## 2026-11-10 — Spring Boot 내장 Tomcat과 실행형 WAR 사용

JSP를 사용할 수 있는 실행형 WAR로 빌드해 별도의 Tomcat 설치 없이 시연한다. jQuery는 WebJar로 포함해 실행 중 외부 CDN에 의존하지 않는다. [Spring Boot JSP 지원 문서](https://docs.spring.io/spring-boot/3.5/reference/web/servlet.html#web.servlet.embedded-container.jsp-limitations)

## 2026-11-10 — 샘플 데이터와 주문 규칙은 서버에서 관리

데이터베이스 설정 없이 주문 흐름을 재현하도록 서버 메모리에 샘플 데이터를 유지한다. 수량과 상태 전이는 서버에서 검증한다. 상태별 건수에는 취소 주문을 포함하고, 주문액 집계에서는 취소를 제외한다.

# Channel Desk

대리점의 상품 주문을 등록하고 출고 진행을 관리하는 ERP 포트폴리오 샘플입니다. **JSP · jQuery · Spring Boot · Java 21**

| 화면 | 주요 기능 |
| --- | --- |
| 주문 관리 | 주문 검색, 상태 필터, 주문 등록, 금액 미리보기, 출고·완료·취소 처리 |
| 상품 관리 | 상품 코드, 분류, 기준 단가 조회와 검색 |
| 대리점 관리 | 지역과 담당자 조회, 대리점별 주문 건수 확인 |
| 주문 통계 | 상태별 주문 건수와 대리점별 주문액 비교 |
